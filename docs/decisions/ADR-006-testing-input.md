# ADR-006 — วิธีทดสอบ paste/drop อัตโนมัติ และข้อจำกัดที่ต้องยอมรับ

- สถานะ: **ตัดสินใจแล้ว** (Phase 0)

## การวัดจริง (spike S5)
ส่ง `ClipboardEvent` และ `DragEvent` สังเคราะห์ที่มี `DataTransfer` แนบไฟล์:

| | chromium | firefox | webkit |
|---|---|---|---|
| paste สังเคราะห์ → ได้ไฟล์ | 1 | **0** | 1 |
| drop สังเคราะห์ 4 ไฟล์ → รับ | 2 | 2 | 2 |
| ปฏิเสธ `evil.svg`, `report.pdf` | ✅ | ✅ | ✅ |

## ข้อค้นพบ
1. **Firefox ไม่รับ `clipboardData` ที่ส่งผ่าน constructor ของ `ClipboardEvent`** → การทดสอบ paste แบบสังเคราะห์ใช้ไม่ได้บน Firefox
   นี่เป็นข้อจำกัดของ **เครื่องมือทดสอบ ไม่ใช่บั๊กของผลิตภัณฑ์**
2. drop แบบสังเคราะห์ทำงานได้ทั้ง 3 เบราว์เซอร์
3. ตัวกรองไฟล์ทำงานถูกต้องทุกเบราว์เซอร์ — SVG ถูกปฏิเสธตามนโยบายความปลอดภัย (ดูข้อ 10 ของแผน)

## การตัดสินใจ
- e2e ของ **drop** ครอบคลุมทั้ง 3 เบราว์เซอร์
- e2e ของ **paste** บังคับรันบน chromium/webkit; บน Firefox ทดสอบผ่านชั้น `extractImages()` แบบ unit test แทน
- แยกตรรกะการแตกไฟล์ออกเป็นฟังก์ชันบริสุทธิ์ `extractImages(dataTransfer)` ที่ unit test ได้โดยไม่ต้องพึ่งเบราว์เซอร์
- **ยังต้องทดสอบด้วยมือ** สำหรับ: Windows Snipping Tool, macOS Cmd+Shift+4, "คัดลอกรูปภาพ" จากเบราว์เซอร์, LINE/Slack — ระบบอัตโนมัติแทนไม่ได้
